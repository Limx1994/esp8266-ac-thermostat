# ESP8266 编译环境路径

本机工具路径见下表；当前构建的检查日期和结果见 [本地发布](README.md#本地发布)。其他机器须按实际安装位置配置，不保证相同路径可用。

| 用途 | 路径 |
| --- | --- |
| ESP8266 RTOS SDK 3.4 | `D:\APPS\Espressif\frameworks\ESP8266_RTOS_SDK` |
| Xtensa LX106 工具链目录 | `D:\APPS\Espressif\tools\xtensa-lx106-elf\esp-2020r3-49-gd5524c1-8.4.0\xtensa-lx106-elf\bin` |
| GCC 编译器 | `D:\APPS\Espressif\tools\xtensa-lx106-elf\esp-2020r3-49-gd5524c1-8.4.0\xtensa-lx106-elf\bin\xtensa-lx106-elf-gcc.exe` |
| SDK 构建脚本 | `D:\APPS\Espressif\frameworks\ESP8266_RTOS_SDK\tools\idf.py` |
| Python 环境 | `D:\APPS\Espressif\python_env\idf5.2_py3.11_env\Scripts\python.exe` |
| CMake 3.13.4 | `D:\APPS\Espressif\tools\cmake\3.13.4\bin\cmake.exe` |
| Ninja 1.9.0 | `D:\APPS\Espressif\tools\ninja\1.9.0\ninja.exe` |

本机既有记录中 Xtensa GCC 为 8.4.0，ESP8266 RTOS SDK 登记为 3.4；既有工具核验结果见本地发布。Python 环境目录虽含 `idf5.2`，本项目使用的 SDK 仍为 ESP8266 RTOS SDK 3.4。

本工作区 Git 根目录为 `D:\空调温度`，固件构建入口为 `D:\空调温度\Sof`，先在 PowerShell 中切换到该目录，再运行 `python build.py`；脚本默认使用上述本机工具，`IDF_PATH` 环境变量仅覆盖 SDK 路径。CMake、Ninja、Python 在默认位置不存在时，脚本从 `PATH` 查找；Xtensa 工具链同样允许从 `PATH` 查找。`Z:` 必须空闲，脚本运行时临时映射该盘符，结束后解除映射。分段固件、`full_flash.bin`、`full_flash.hex` 和 `flasher_args.json` 均在 `build\auto\`，无需预先创建英文路径入口。规则测试使用上述 Ninja，以 `-j 12` 执行 `tests\build.ninja`。

`sdkconfig.defaults` 分别设置 ESP-12F 晶振和 Flash 频率为 26 MHz，UART0 固件日志和串口监视器为 115200 baud。项目 `flash.py` 独立使用默认烧录速率 460800 baud，连接不稳定时传入 `--baud 115200`；烧录速率不改变日志速率。构建生成的 `sdkconfig` 被 Git 忽略，实际参数以 `sdkconfig`、`build\auto\config\sdkconfig.h` 和 `build\auto\flasher_args.json` 为准。

CPU 固定为 80 MHz（按配置重新构建可回退 160 MHz），自动 light sleep 需 `CONFIG_PM_ENABLE=y`；HTTP 请求头与 URI 上限分别为 2048、1024 字节。defaults 不覆盖已有 `sdkconfig`，增量构建前须核对这些参数。`components\esp_http_server` 与 `components\esp8266` 从 `IDF_PATH` 复用 SDK 配置和实现，不能脱离 SDK 单独构建。定时器开关在构建目录生成源码及静态库副本，原 SDK 保持不变；源码或对象布局不匹配时构建报错。配置开关见 [休眠与供电](README.md#休眠与供电)。

主机测试另需 `PATH` 中可用的 GCC、Python 和 Node.js，与固件的 Xtensa 编译器及构建脚本选用的 Python 环境不同。基础主机检查使用 GCC、Python 和 Node.js；覆盖统计另使用 gcov 与本地 Python coverage，且依赖尚未提交的工作区运行器。完整检查命令见 [软件检查](README.md#软件检查)，工具版本记录和最新构建结果见 [本地发布](README.md#本地发布)。
